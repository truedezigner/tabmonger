TabMonger

Browser connection

Make every new tab yours.

Run TabMonger on one computer, then paste the address it shows here. Every browser on your home network can point to the same dashboard.

Enter the address shown in the TabMonger launcher.

No account, analytics, browsing history, or remote service is used. The extension stores only this base address and your two choices in local browser storage. URL credentials, query strings, and fragments are never saved.

Want the browser's original new-tab page back? Pause above, disable the extension, or clear its setup.
