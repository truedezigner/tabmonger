# Community customizations

This directory is a home for small, reviewable TabMonger CSS and JavaScript recipes.

Recipes must be optional, contain no analytics or remote code, make no network requests, and explain exactly what they change. Users copy a recipe into **Settings → Advanced** only after reviewing it.

See [Extending TabMonger](../docs/EXTENDING.md) for the security model and [CONTRIBUTING.md](../CONTRIBUTING.md) before proposing a new example.
